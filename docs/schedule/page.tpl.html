Critical path

The penetration test sits on this path and falls over the Christmas–New Year period, when testers book out. Book it in the first week. The terms, privacy policy and data agreement have plenty of slack, but must be done before go-live.

How the six streams run

  • Each stream is its own Claude Code cloud session on its own branch, working from the shared docs and CLAUDE.md.
  • Streams only touch their own module folders. Shared parts (schema, permissions) change only in Stream 1.
  • Each finished ticket arrives as a pull request with tests passing. You try it on staging and merge.
  • Your review time is the real limit. Six streams peak in early December. If that's too many to review, pause the streams with slack first; the critical ones keep going.

Ways to finish sooner

  1. Have Caring For You sign off the prototypes in 2 days instead of 5. That brings everything after it forward 3 working days.
  2. Book the penetration tester now for 29 December to 8 January. Testers book out over the holidays, and this test sits on the critical path.
  3. Start the Caring For You data export early. Your current system's export format sets how long the import takes.
  4. Start the Apple and Google developer accounts this week. Apple needs a D-U-N-S number for a company account, and store review slows over Christmas, when the app release falls.
  5. Keep the first release to the agreed list. Every addition on the red path moves the finish date.

Assumptions. Durations are working days and include your review time. Victorian public holidays are excluded. No Christmas shutdown is assumed for the build: a two-week break moves everything after 18 December out by about two weeks. The payroll specialist, penetration tester and the lawyer drafting terms are assumed available when needed. Estimates will tighten after the first two weeks of real build speed.
