# CROP Workforce Management

**C**redentials · **R**ostering · **O**perations · **P**eople — multi-tenant workforce platform for staffing agencies. Web: cropwms.com.

Beta client: Caring For You (nursing agency).

## Release 1
Roster, allocations (casual shift offers and broadcast), credentialing, client portal, native iOS/Android worker app, notifications (push, SMS, email), click to call.

## Release 2
Timesheets, payroll and invoice export (Xero/MYOB, Employment Hero).
